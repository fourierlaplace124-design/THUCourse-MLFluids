\subsection{学习目标与定义}
本讲示例围绕速度场及其散度，展示定义、推导、计算和记录方式。
记录课程内容时，应补充假设条件、符号含义及教材页码。

\begin{definition}[速度场]
\label{def:velocity}
设流动区域为 $\Omega\subset\R^d$，时间区间为 $I\subset\R$。
速度场 $\vect{u}\colon\Omega\times I\to\R^d$ 表示位置
$\vect{x}$、时刻 $t$ 处的流体速度。
\end{definition}

对空间变量连续可微的速度场，散度定义为
\begin{equation}
  \nabla\cdot\vect{u}
  =\sum_{i=1}^{d}\frac{\partial u_i}{\partial x_i}.
  \label{eq:divergence}
\end{equation}
公式~\eqref{eq:divergence} 中，各分量与坐标方向一一对应。

\begin{theorem}[散度的线性性]
\label{thm:linearity}
若 $\vect{u},\vect{v}\in C^1(\Omega;\R^d)$，且 $a,b\in\R$ 为常数，则
\[
  \nabla\cdot(a\vect{u}+b\vect{v})
  =a\nabla\cdot\vect{u}+b\nabla\cdot\vect{v}.
\]
\end{theorem}
\begin{proof}
将公式~\eqref{eq:divergence} 应用于各分量，由偏导数的线性性即可得到结论。
\end{proof}

\begin{example}[二维速度场]
对 $\vect{u}(x,y)=(x,-y)$，有
\begin{align}
  \frac{\partial u_1}{\partial x}&=1, &
  \frac{\partial u_2}{\partial y}&=-1,\\
  \nabla\cdot\vect{u}&=1-1=0.
\end{align}
因此该速度场处处满足散度为零。
\end{example}

\begin{remark}
定理~\ref{thm:linearity} 中 $a,b$ 为常数；若它们随空间位置变化，
需要使用乘积法则，不能直接套用该结论。
\end{remark}

\subsection{计算与资料记录}
代码~\ref{lst:divergence} 用中心差分近似上例中的散度。
这里的代码块仅用于展示，编译笔记不会运行程序。

\begin{lstlisting}[language=Python,caption={中心差分计算散度},label={lst:divergence}]
def divergence(x, y, h=1e-5):
    # 中心差分：分别计算两个方向的偏导数
    u = lambda x, y: x
    v = lambda x, y: -y
    du_dx = (u(x + h, y) - u(x - h, y)) / (2 * h)
    dv_dy = (v(x, y + h) - v(x, y - h)) / (2 * h)
    return du_dx + dv_dy

print(divergence(1.0, 2.0))  # 结果应接近零
\end{lstlisting}
